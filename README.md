# XAiPromagranate

A deep learning project for classifying pomegranate fruit diseases from image data.

## Overview

This repository contains a Google Colab/Jupyter notebook that:

- downloads the Kaggle dataset for pomegranate fruit diseases,
- prepares the image data for model training,
- trains a convolutional neural network (CNN) or related image classifier,
- evaluates performance and visualizes results,
- optionally saves model outputs for later use.

The notebook is centered around the dataset:

- https://www.kaggle.com/datasets/sujaykapadnis/pomegranate-fruit-diseases-dataset

## Repository contents

- `XAiPomegranateipynb.ipynb` — main notebook for dataset download, preprocessing, training, and evaluation
- `README.md` — project overview and setup instructions
- `requirements.txt` — Python dependencies
- `.gitignore` — ignores large dataset files and local environment artifacts
